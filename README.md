# Foamix Landing Page

**Foamix** is a modern landing page for a company that provides polyurethane foam (PU foam) insulation services across Ukraine.

## About the Project

This project was created to present Foamix services, explain the advantages of PU foam insulation, and generate leads from potential customers.

The website helps users:

- quickly understand what polyurethane foam insulation is;
- explore the main benefits of the technology;
- learn which types of properties can be insulated;
- review the stages of cooperation;
- find answers to frequently asked questions;
- submit a request for a consultation or a cost estimate.

## Main Features

- hero section with a clear value proposition and call to action;
- sections highlighting the benefits of PU foam insulation;
- overview of different polyurethane foam types;
- comparison block for thermal insulation performance;
- step-by-step explanation of the company workflow;
- FAQ section;
- contact form for requesting a quote;
- privacy policy and cookies pages;
- SEO metadata and Open Graph configuration for better search and social media visibility.

## Project Goal

The main goal of the website is to attract new customers, increase trust in PU foam insulation services, and convert visitors into leads.

## Target Audience

- owners of private houses and cottages;
- owners of warehouses, hangars, and commercial properties;
- customers looking to reduce heating and cooling costs;
- clients searching for durable and energy-efficient insulation solutions.

## Technologies

The project is built with:

- Tailwind CSS
